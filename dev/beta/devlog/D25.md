## Shared mechanics (ui3.js, tools part)
- `tv(u,id,lo,hi,unit)` / `pv(u,id,lo,hi)`: accept a decimal comma (`ui3tNum`), return null for blank, non-numeric or out-of-range input, mark the field `aria-invalid` (red outline) and queue "Check <field>: outside a plausible range (lo–hi unit)". Pressure limits are in mmHg and shown in the user's unit.
- `ui3tRun(u,ids,fn)`: every run blanks all readouts to "—" first, then shows either the input problems or the verdict that fn returns. No stale results.
- `wire()`: number inputs become `type=text inputmode=decimal` (Chromium drops "5,3" from type=number); verdict line gets `role=status aria-live=polite`; inputs are remembered per tool for the session (`UI3T.mem`); adds "Copy result" and "Reset" buttons.
- `ui3tCSS()`: injected style for invalid fields and pocket print layout; an `@page A4` rule is added only on `beforeprint` while the pocket card is showing (so other printouts keep their own page setup).
